# Figma import files

One file per design and device. In Figma, create three pages (A – Nocturne, B – Liner Notes, C – Colour)
and drag the matching files onto each page. Each SVG imports as a single frame at the true page size
(1440 px wide for desktop, 390 px for mobile), built from high-resolution (2x) image slices.

| Figma page | Desktop | Mobile |
|---|---|---|
| A – Nocturne | `a-nocturne-desktop.svg` | `a-nocturne-mobiel.svg` |
| B – Liner Notes | `b-liner-notes-desktop.svg` | `b-liner-notes-mobiel.svg` |
| C – Colour | `c-colour-desktop.svg` | `c-colour-mobiel.svg` |

These are pictures of the pages, not editable layers. The interactive timeline and the scroll animations
only work in the live HTML pages under `designs/`.
